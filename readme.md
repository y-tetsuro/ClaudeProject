# AI時短術オンライン講座

ビジネスパーソン向けに、AIツールを活用して日常業務を効率化するスキルを身につけるオンライン講座サービスです。

## サービス概要

- **対象者**: AIを業務に活用したいビジネスパーソン（初心者〜中級者）
- **形式**: 動画講座 ＋ 演習課題 ＋ コミュニティサポート
- **期間**: 全8週間（週2〜3時間の学習目安）
- **価格**: 49,800円（税込）／ 月額プラン 5,980円〜

## カリキュラム構成

| 週 | テーマ | 内容 |
|----|--------|------|
| 1週目 | AI入門 | ChatGPT・Claude・Geminiの使い分け |
| 2週目 | 文章生成 | メール・報告書・提案書の自動生成 |
| 3週目 | データ分析 | ExcelデータをAIで瞬時に解析 |
| 4週目 | 画像・資料作成 | プレゼン資料・画像の自動生成 |
| 5週目 | 業務自動化 | ノーコードツール × AI連携 |
| 6週目 | 情報収集・調査 | AIによるリサーチ・まとめ術 |
| 7週目 | プロンプト設計 | 精度を上げるプロンプトエンジニアリング |
| 8週目 | 実践演習 | 自分の業務に合わせた活用プラン策定 |

## 主な特徴

- **即実践可能**: 学んだ内容をその日から業務に活用できる実践的なカリキュラム
- **業種別テンプレート**: 営業・マーケ・総務・人事など職種別のプロンプトテンプレート付き
- **Q&Aサポート**: 受講期間中はSlackコミュニティで質問し放題
- **アップデート保証**: AIツールの進化に合わせてコンテンツを随時更新

## 技術スタック（サービス構築）

- フロントエンド: HTML / CSS / JavaScript
- 動画配信: Vimeo / YouTube Private
- 決済: Stripe
- コミュニティ: Slack / Discord
- LMS（学習管理）: Teachable / 独自開発
