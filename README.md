# AI社員で会社を経営する（Claude Code）

このリポジトリは、[【実演】Claude CodeでAI社員を使って会社経営する方法](https://youtu.be/505xfQaEtxU) の構成を、自分の会社用に作った雛形です。
メインのClaudeを「社長室」、各部署（サブエージェント）を「AI社員」として、1人で会社を回すための土台です。

## これは何？

- **あなた** = 社長。日本語で指示を出すだけ。
- **メインのClaude** = 社長室 / PM部。指示を受けて担当部署に振り分け、結果をまとめて報告する。
- **AI社員（5部署）** = 経営戦略部・マーケ部・エンジニア部・会計財務部・品質管理部。

## まず最初にやること（重要）

1. **`CLAUDE.md` の「1. 事業定義」を埋める。**
   - ここが会社の頭脳です。会社名・事業内容・ターゲット顧客・今月の目標などを書くほど、AI社員が的確に動きます。
   - 全部埋まっていなくてもOK。分かる範囲から書いて、あとで育てていけます。

## 使い方（例）

Claudeに日本語で話しかけるだけです。例えば：

- 「うちの事業のSNS投稿を3本作って」 → マーケ部が作る
- 「この料金設定で採算が取れるか計算して」 → 会計財務部が試算する
- 「今月まず何をやるべきか戦略を立てて」 → 経営戦略部が提案する
- 「今できたLPの文章、品質チェックして」 → 品質管理部がダメ出しする

メインのClaudeが、どの部署（AI社員）に振るかを自動で判断します。
「戦略を立ててから作って、最後に品質チェックまでして」のように、複数部署をまたぐ指示もできます。

## AI社員（部署）一覧

| 部署 | 役割 | 得意なこと |
|------|------|-----------|
| 経営戦略部 | 計画者 | 目標設定・戦略・優先順位づけ |
| マーケティング部 | 実行者 | SNS・広告・LP・コピー・コンテンツ |
| エンジニア部 | 実行者 | サイト・アプリ・自動化 |
| 会計・財務部 | 実行者 | 売上/コスト試算・数字管理 |
| 品質管理部 | 評価者 | 成果物のチェック・ダメ出し |

各社員の設定は `.claude/agents/` にあります。役割を変えたいときはこのファイルを編集します。

## フォルダ構成

```
CLAUDE.md              会社の就業規則・業務マニュアル（AI社員はこれに従う）
README.md              このファイル（社長＝あなた向けの使い方）
.claude/agents/        AI社員（サブエージェント）の定義
01_経営戦略/           戦略メモ・事業計画
02_マーケティング/     SNS・LP・コピー
03_開発/               サイト・アプリ・スクリプト
04_会計・財務/         試算・数字管理
05_品質管理/           レビュー記録
```

## カスタマイズ

- **役割を変える / 増やす** → `.claude/agents/` にファイルを足す・編集する。
- **会社のルールを変える** → `CLAUDE.md` を編集する。
- 迷ったら、Claudeに「この会社の設定をこう変えたい」と相談すればOKです。
